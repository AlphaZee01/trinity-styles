# Project: Trinity Styles

## Project Overview
Build a complete, production-ready clothing e-commerce website and CRM system called **Trinity Styles**.

Trinity Styles is a modern fashion store that lets customers browse clothing, virtually try on garments with AI, add items to cart, and pay securely. It also includes a full admin/CRM dashboard for managing products, orders, customers, and try-on analytics.

**Important constraints:**
- Fully custom (no Shopify, WooCommerce, or Medusa)
- Backend & database: Supabase (Postgres + Auth + Storage)
- Payments: Paystack
- Virtual Try-On: RunPod Serverless API (hosting an open-source VTON model)
- Hosting: Render (Next.js web service)
- Frontend: Next.js 15/16 (App Router) + TypeScript + Tailwind CSS + shadcn/ui
